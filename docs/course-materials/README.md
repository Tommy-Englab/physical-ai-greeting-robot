# 講座資料（course-materials）

Physical AI 応用1 講座の資料を置くフォルダです。

## 使い方

- 参照したい講座資料（PDF・スライド・文字起こし等）をこのフォルダに置く。
- ここに置いたファイルはAIが読んで、環境構成やタスク設計の判断に使える。

## 注意: 資料そのものはGitHubに上げない

講座資料は著作物であり、提出物は受講者へ公開される可能性があるため、
資料ファイル本体はコミットしない。`.gitignore` で、この `README.md` を除く
このフォルダ内のファイルを除外している。

- OK: このフォルダにファイルを置いてAIに読ませる（ローカルのみ）
- NG: 資料ファイルをGitHubへpushする

公開してよい資料だけを例外的にコミットしたい場合は、その都度 `.gitignore` を調整する。
