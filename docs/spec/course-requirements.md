## 1. 課題概要
- 課題名: AI×ロボティクスによる創造的タスクの実現
- 目的: AI技術を活用し、ロボットが実行するタスクを設計・実装することで、創造性と技術力を発揮する。
- 対象: Physical AI 応用1講座の受講者
- 提出物: 実行動画 / 使用コード一式 / 簡単なレポート

## 2. 課題内容・使用ツール
- 受講者が自由に設定したタスクをロボットに実行させる。
- 使用ツール: 講義で使用した ROS / Gazebo / Genesis などのロボットシミュレータを想定。他ツール・実機も可。

## 3. AIの使用
- 何らかの形でAIを使用することが必須。推論のみでも可。学習は任意（既存モデル・AIサービス利用も可）。

## 4. タスクの設定
- タスクは受講者が自由に設定。例: 物体操作 / 画像認識 / 自然言語制御 / 複数動作の組み合わせ / 状況に応じた動作 / AI判断に基づく行動 / 自律行動。

## 5. 提出物（3点）

### 5.1 実行動画（YouTube）
- ロボットがタスクを実行する様子（MP4）を自分のYouTubeアカウントにアップロードし、そのURLをomnicampusの指定フォームに提出。
- 長さ: 1分〜3分以内。2倍速再生可。倍速の場合は動画内または概要欄に明記。
- タイトル: `PAI最終課題_omnicampusアカウント名` または `PAI最終課題_アカウントID`（個人名をアカウント名に使っている場合はアカウントIDを使う）
- 公開設定:
  - 限定公開（リンクを知っている人のみ閲覧可）: 必須（最低条件）
  - 全体公開: 推奨（公開なら優秀生選出で加点対象。限定公開でも選出自体は可）
  - 「子ども向け動画」「年齢制限」は「いいえ」
  - 「インスタントプレミア公開」はチェックしない
  - 予約公開を使う場合は締切までに公開日時を設定
  - 採点完了まで動画を削除・非公開にしない

### 5.2 使用コード一式（GitHub）
- GitHubリポジトリのURLをomnicampusに提出。
- リポジトリの公開設定は必ず「public」にする。
- 含めるもの（必要に応じて）: ロボット制御コード / AI推論コード / センサ処理 / シミュレータ起動ファイル / ROSパッケージ / 設定ファイル / 実行手順に必要なファイル。

### 5.3 レポート（PDF、omnicampus提出）
- ファイル名: `説明資料_PAI最終課題_omnicampusアカウント名.pdf`
- 少なくとも次を含める: 課題の概要 / 設定したタスク / タスクの目的 / 使用した環境・ツール / 使用したAI技術 / システムの構成 / 実装方法 / 工夫した点 / 実行結果 / 今後の改善点

## 6. 評価基準
- 合格ライン: ロボットがタスクを実行している動画および提出物を提出すれば合格。
- 加点要素: 創造性（独自性）/ 技術力（高度・複雑な制御）/ 実用性（現実世界での応用可能性）/ 表現力（動画構成・説明の分かりやすさ）。
- 剽窃・サンプル丸写し・無関係ファイル提出は修了判定対象外となる可能性。

- 提出は「omnicampusでの提出（レポートPDF＋GitHub URL）」と「YouTubeへの動画アップロード＋そのURLをomnicampusフォームへ」の両方を行う。詳細な提出手順は omnicampus 案内の Notion にまとまっている（提出時に参照）。優秀生選出希望なら提出後の「最終課題_優秀生選出用」からも成果物を提出する。
